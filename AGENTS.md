This is an Expo (SDK 58) / React Native app with a Supabase backend. Read docs/architecture.md first.

- Navigation uses **React Navigation** (a project requirement), not Expo Router. Navigators live in `src/navigation`.
- Install native packages with `npx expo install <pkg>` so versions match the SDK.
- Native folders (`android/`, `ios/`) are generated by `npx expo prebuild`; configure them via `app.config.ts`.
- Expo APIs change between SDKs: check https://docs.expo.dev/versions/v58.0.0/ before using one.
- All database writes go through Postgres functions in `supabase/migrations`. New client-callable functions must be added to the allowlist in `20261022000700_function_grants.sql` (a test enforces the exact list).
- Never reference the service-role key or other secrets from `src/` (a test scans for them).
- Before finishing: `npm run typecheck && npm run lint && npm test && npm run test:db`.
